## Historical audit records

Files with names beginning with `PHASE`, `BETA11`, or `RECONSTRUCTION` are retained as historical reconstruction/audit evidence. They are not the current release status or user configuration guide.

The `baseline/` directory contains hashes and verification records for the original binary baseline used during source reconstruction.
